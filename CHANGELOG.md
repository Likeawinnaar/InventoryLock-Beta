# Changelog

## 1.0.5

- Enabled **Per-Server Locks** by default for new installations and configurations without a saved choice.
- Kept existing preferences. Turn the setting off to use shared locks and back on to restore your saved server-specific locks.

## 1.0.4

- Added independent **Per-Server Locks** and **Per-World Locks** options.
- Added lock icons and color overlays to the hotbar during gameplay.
- Improved overlay visibility on occupied slots while keeping item counts readable.

## 1.0.3

- **Unlock All** now clears and saves the active lock set on confirmation. Other settings save when you press **Done**.
- Replaced the 16 padlock textures with the redesigned 32 × 32 sprites.

## 1.0.2

- Added 16 selectable padlock colors and the golden Mod Menu logo.
- Mapped the old **Gold** setting to **Yellow**.

## 1.0.1

- Kept InventoryLock's settings in English when Minecraft uses another language.
- Improved the padlock's visibility on empty and occupied slots.

## 1.0.0

- Added client-side locks for personal inventory, hotbar, and offhand slots.
- Saved lock sets per launcher profile and added optional Mod Menu configuration.
- Targeted Minecraft Java Edition 1.21.1 with Fabric and Java 21.
