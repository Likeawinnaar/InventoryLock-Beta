# Contributing

Thanks for taking an interest in InventoryLock.

InventoryLock is proprietary and in beta. The public repository contains the source and tracks issues. See [LICENSE](LICENSE) for the terms.

## Bug reports

Please use the provided issue template. Include reproducible steps, the
exact Minecraft/Fabric/mod versions and, when possible, screenshots or
sanitized logs. Check whether the issue is already reported.

## Feature requests

Explain the player problem and your suggested behavior. Avoid assuming a
feature already exists in a released build.

## Code contributions

Do not post copied mod source, decompiled code, another author's code or
third-party assets without authorization. Source contributions and their
copyright terms require the project owner's prior agreement. Opening an
issue does not grant permission to use InventoryLock branding or code.

For security vulnerabilities, read [SECURITY.md](SECURITY.md).
