# Repository setup

This repository hosts the InventoryLock beta, including its Gradle project,
Java source, shipped assets, and screenshots. See [LICENSE](LICENSE) and
[NOTICE.md](NOTICE.md) for reuse terms and credits. Keep access tokens, machine
configuration, private artwork, logs, and game saves out of commits.

Build instructions are in [README.md](README.md#build-from-source) and
[docs/BUILD_NL.md](docs/BUILD_NL.md). The existing manual Actions workflow is
restricted to private repositories. The command-line build works from a public
checkout.

Use the [release checklist](RELEASE_PROCESS.md) before distributing a new build.
