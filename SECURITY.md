# Security policy

InventoryLock is in **beta**. Security issues and unintended client behavior
should be reported responsibly.

## Reporting a vulnerability

Do **not** publish exploit details, credentials, private files or personal
information in a public issue.

Contact the repository owner through their GitHub profile, or use GitHub's
private vulnerability reporting feature **if it has been enabled** in the
repository settings. Include the affected Minecraft version, mod version,
other installed mods, steps to reproduce and impact.

Do not send world saves or logs containing passwords, access tokens, addresses
or other private data. Please allow the maintainer to review the report
before disclosing detailed vulnerability information publicly.

## Supported versions

No verified release/version compatibility matrix has been supplied to this
repository yet. Until a release has been validated, no version is promised
security-maintenance coverage.
